# 학습 로드맵

목표: **개발 실력 키우기 + 내 전용 홈페이지 + (나중에) 로그인·멀티테넌트 + 지식 저장소.**
연습한 결과가 그대로 홈페이지 기능이 되도록, 쉬운 것부터 한 단계씩 쌓는다.

| 단계 | 할 일 | 배우는 개념 | 완성되는 것 | 상태 |
|---|---|---|---|---|
| [0](00-tour.md) · [흐름](00-flow.md) | 지금 있는 앱 둘러보기 | 서버, 포트, HTTP, JSON, API 문서 | (구경) | 진행 중 |
| 1 | DB 없이 API 만들어 보기 | 경로/쿼리/본문, 상태코드, Pydantic 검증 | 연습용 API | |
| 2 | 첫 테이블 만들기 | ORM, 마이그레이션, 테이블 설계 | `todo` 테이블 | |
| 3 | 할 일 CRUD API | REST, 의존성 주입, 테스트 | `/todos` API | |
| 4 | 할 일 웹 화면 | 서버/클라이언트 컴포넌트, 폼, Server Action | `/todos` 페이지 | |
| 5 | 홈 대시보드 | 데이터 모아 보여주기, 날짜·시간대 | 오늘 할 일 한눈에 | |
| 6 | 노트 (자격증 요약 등) | 마크다운, 태그, 검색, 1:N 관계 | 지식 저장소 | |
| 7 | 로그인 | 비밀번호 해시, 토큰(JWT), 보호된 API | 내 계정 | |
| 8 | 멀티테넌트 | 데이터 소유자 구분, 격리, 권한 | 여러 사람이 쓰는 서비스 | |

7~8단계에서는 "혼자 쓰려고 만든 테이블에 나중에 소유자(user_id)를 붙이는 마이그레이션"을 직접 겪는다. 실무에서 자주 겪는 일이다.

## 단계마다 하는 방식

1. **개념 설명**: 왜 필요한지부터
2. **직접 해보기**: 코드는 되도록 직접 타이핑
3. **일부러 망가뜨려 보기**: 에러를 보고 원인 찾기
4. **기록**: 이 폴더에 단계별 문서(`NN-주제.md`)를 쌓고, 막힌 점은 devlog에 남긴다

## 개념 사전

배운 용어를 한 줄씩 모아 둔다.

| 용어 | 뜻 | 처음 배운 단계 |
|---|---|---|
| 서버 | 계속 켜져서 요청을 기다리는 프로그램 | 0 |
| 포트 | 한 PC 안의 문 번호. `localhost:8000` = 내 PC 8000번 문 | 0 |
| HTTP | 브라우저와 서버의 대화 형식. 메서드 + 주소 → 상태코드 + 본문 | 0 |
| JSON | `{"키": "값"}` 데이터 형식 | 0 |
| API | 프로그램끼리 대화하는 창구 | 0 |
| OpenAPI | API 명세 표준. FastAPI가 `/docs`, `/openapi.json`으로 자동 생성 | 0 |
| 의존성 주입 | 함수가 필요한 것(DB 세션 등)을 직접 만들지 않고 밖에서 넣어 받는 것. FastAPI의 `Depends` | 0 |
| 미들웨어 | 모든 요청이 거쳐 가는 검문소 (CORS 등) | 0 |
| 라우터 | (메서드, 주소) → 실행할 함수를 찾아 주는 표 | 0 |
| 연결 풀 | DB 연결을 모아 두고 돌려 쓰는 것. `engine`이 관리 | 0 |
| 드라이버 | Python과 DB 사이의 통역사 (`psycopg`) | 0 |
| Suspense | 준비될 때까지 대체 화면을 먼저 보여 주는 React 기능 | 0 |
