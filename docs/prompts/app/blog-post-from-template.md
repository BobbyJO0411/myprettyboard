# 템플릿 기반 블로그 글 생성 (초안)

> 블로그 자동 작성 기능에서 server가 AI API에 보낼 프롬프트의 초안.
> 블로그 플랫폼과 템플릿 구조가 정해지면 확정한다.

## 입력 변수

| 변수 | 설명 |
|---|---|
| `{{template}}` | 저장된 글 템플릿 (구조, 섹션 제목 등) |
| `{{topic}}` | 이번 글의 주제 |
| `{{keywords}}` | 포함할 키워드 |
| `{{tone}}` | 말투 (예: 친근한 존댓말) |
| `{{length}}` | 분량 (예: 1500자 내외) |

## 프롬프트

```
당신은 {{tone}} 말투로 글을 쓰는 블로그 작가입니다.
아래 템플릿 구조를 그대로 따라 "{{topic}}" 주제의 글을 작성하세요.

<template>
{{template}}
</template>

조건:
- 분량: {{length}}
- 다음 키워드를 자연스럽게 포함: {{keywords}}
- 사실이 불확실한 내용은 단정하지 말 것
- 출력 형식: Markdown. 첫 줄은 "# 제목"
```
